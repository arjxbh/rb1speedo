Adds an UPDATES button at the top left of the speedometer. It opens the latest GitHub release in your browser; download RB1-Speed.apk and open it to install the update.

The app retains its foreground-only GPS behavior and has no Internet permission. Updates use the existing prototype development signing key so they can install over previous builds signed with that key.

Build checks cover compilation, speed-model tests, APK alignment, and signature verification. Visual appearance, the browser/installer flow, live GPS, and installation over the existing app still require a physical phone check.

Android 8.0 or newer. Personally built development-signed APK, not a Play Store release.
